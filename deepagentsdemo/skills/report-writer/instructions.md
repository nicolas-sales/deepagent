# Report Writer - Instructions

Every final answer must follow this structure, in this order:

```
# Report: <short title>

## Summary
2-3 sentences answering the question directly.

## Details
The main content: explanations, code, tables. Use short sections and bullet points.

## Skills used
List of the skills applied (e.g. python, langgraph, aws, report-writer).

## Sources
- Files read (e.g. /AGENTS.md, /skills/...) and external references.
- If no verifiable source: write "No external source verified".

## Next steps
1-3 concrete actions the user can do next.
```

## Rules
- Answer in the language of the user's question.
- Keep the report concise: no more than needed to answer.
- Never invent sources.
