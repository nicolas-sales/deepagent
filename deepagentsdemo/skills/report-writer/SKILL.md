# Report Writer Skill

## When to use
- For EVERY final answer to the user, after any other skill has been applied.

## How to use this skill
1. Read `/skills/report-writer/instructions.md` for the report structure.
2. Read `/skills/report-writer/examples.md` for a complete example.
3. Write the final answer following that structure.
